# 제공자 간 순차 인계

## 동작

클라우드 연결 작업에서 마스터가 다른 구독 실행 환경이 유용하다고 판단하면 같은 작업 ID를 유지하며 Codex와 Claude 사이에 순차 인계할 수 있습니다. 예: Codex 초안 → Claude 검토 → Codex 반영. 각 제공자의 마스터가 먼저 요청과 검증 기준을 이해하고 내부 하위 모델을 선택합니다. 단순 작업은 인계하지 않습니다.

- Codex 데스크톱 연결기는 구조화된 결과의 handoff를 클라우드에 전달합니다.
- Claude Routine은 인증된 handoff_task 도구로 진행과 다음 단계의 이유·지시·검증 기준을 기록한 뒤 종료합니다.
- Claude가 대상이면 Worker가 새 실행권을 잡고 Routine을 호출합니다. Codex가 대상이면 데스크톱 대기열에 넣습니다.
- 이전 실행기의 쓰기는 차단합니다. 같은 인계 응답을 재전송해도 작업이나 Claude 세션을 다시 만들지 않습니다.
- 인계받은 Codex 실행에는 지정된 기존 생성 파일을 안전한 이름으로 준비하고 경로 목록을 전달합니다. 입력 원본은 복제하지 않습니다.
- 화면의 재개 지점에 제공자 인계 이력과 대기 상태를 표시합니다.

## 제한과 복구

한 작업당 최대 두 번 인계합니다. 첨부 원문 또는 URL 참조가 있는 작업은 자동 인계하지 않습니다. 원문이 필요한 연구 작업은 재연결·별도 실행 흐름을 이용해야 합니다. 인계하는 생성 결과는 최대 20개, 인코딩된 내용 합계 5 MB이며 실제 결과 전달 경로의 기존 요청 크기 제한도 적용됩니다. 초과하면 조용히 잘라내지 않고 오류를 표시합니다.

PC가 꺼져 있으면 Codex 단계는 queued에 머뭅니다. Claude 단계는 연결된 클라우드 Routine에서 실행합니다. 구독 한도·인증 실패를 우회하려고 다른 제공자로 전환하지 않습니다. 자동 임대 만료 후 결과 재전송은 같은 실행권과 변경되지 않은 중단 버전일 때만 복구합니다. 수동 중단·취소·새 요청 후의 늦은 결과는 차단합니다.

Worker가 실행권을 기록한 뒤 Routine 요청 전 비정상 종료되는 극단적인 경우까지 exactly-once 실행을 보장하지는 않습니다. 실행이 시작됐는지 불확실한 네트워크 오류는 자동으로 새 세션을 반복 생성하지 않습니다. 체크포인트와 Claude 세션을 확인한 뒤 명시적으로 재개해야 합니다.

현재 기능은 순차 인계입니다. 여러 Codex/Claude 하위 작업을 동시에 실행하고 상위 마스터가 자동 병합하는 트리는 아직 구현되지 않았습니다. 로컬 단독 SQLite 서버는 교차 제공자 인계 도구를 노출하지 않습니다. 모델 선택의 적절성·절감률은 보장값이 아니며 배정 보고서는 자기보고입니다.
