# 기존 작업 기록의 클라우드 통합

## 데스크톱에 저장된 기록
1. `Start INNO Workspace.cmd`를 실행하고 `.inno/DESKTOP-ACCESS.md`의 개인 링크로 접속합니다.
2. 왼쪽 아래 **작업실 연결** → **기존 로컬 기록 선택**을 누릅니다.
3. 가져올 기록을 선택하고 **선택한 기록 가져오기**를 누릅니다.

프로젝트의 `.inno/tasks.sqlite`를 읽기 전용으로 조회합니다. 이 DB와 기존 로컬 전용 모드는 유지됩니다. 2026-09-14 실제 조회에서는 이전 대상 기록이 0개였습니다.

## JSON으로 내보낸 기록
휴대폰·다른 브라우저의 ‘이 기기 보관’ 기록은 해당 기기에서 먼저 내보내세요. 클라우드 작업실의 **작업실 연결 → 작업 기록 가져오기**에서 JSON 파일을 고르면 기록 목록을 검토하고 선택할 수 있습니다. 다른 브라우저나 다른 출처의 저장소를 몰래 읽지 않습니다.

## 중복과 충돌
- 동일한 기록: 이미 있음으로 표시하고 건너뜁니다. 이후 클라우드에서 수정한 내용도 보존합니다.
- 같은 ID지만 다른 내용: 충돌로 표시하고 기존 기록을 유지합니다.
- 충돌 기록도 보관하려면 **충돌 기록을 별도 사본으로 보존**을 선택해 다시 가져옵니다. 기존 기록을 유지하는 대신 사본 수가 늘어납니다. 같은 사본을 재시도해도 중복 생성하지 않습니다.
- 대기·실행 중이던 기록은 일시정지로 가져옵니다. 가져오기가 AI 실행을 자동 시작하지 않습니다.

대화, 계획, 체크포인트의 내용, 결과 파일, 원본 참조 메타데이터를 보존합니다. 이전 실행권과 첨부 원본 바이트·알 수 없는 인증 필드는 제외합니다. 원본 파일은 작업을 실행할 때 다시 연결해야 합니다. 사용자가 대화 본문에 직접 적은 내용은 대화의 일부로 보존됩니다.

## 효율성과 한도
로컬 목록은 50개씩 읽고, 선택한 기록만 한 건씩 전송합니다. 다음 페이지로 이동하면 현재 선택이 초기화됩니다. 진행 결과는 가져옴·이미 있음·충돌·실패로 구분합니다. 일부 전송이 실패하면 성공한 기록은 남고, 같은 파일을 다시 선택해 안전하게 재시도할 수 있습니다.

JSON 파일은 20 MB/500개 이하, 정규화된 개별 기록은 680,000 UTF-8바이트 이하입니다. 초과·손상된 기록을 잘라서 가져오지 않으며 원본을 보존하고 오류로 표시합니다. 대용량 결과물 전송 확대는 별도 후속 작업입니다.
