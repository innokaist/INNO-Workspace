# 데스크톱과 클라우드 작업 연결

## 이번에 가능한 흐름
클라우드 INNO에서 첨부 없는 작업을 만든 뒤 Codex를 선택하여 실행하면, 켜져 있는 데스크톱 연결기가 작업을 가져옵니다. 답변과 생성 결과는 같은 클라우드 작업에 저장되어 휴대폰에서도 확인할 수 있습니다. 기존 로컬 전용 작업 기록은 그대로 별개로 보존됩니다.

## 실행
프로젝트의 `Start INNO Cloud Bridge.cmd`를 실행합니다. Node.js 24와 ChatGPT 구독으로 로그인한 Codex가 필요합니다. 현재 Codex 앱 터미널에서는 `node scripts/desktop-bridge.mjs`로 실행할 수 있습니다. 기존 `.inno/cloud-access-token.txt`를 사용하며 키를 다시 입력할 필요는 없습니다. Ctrl+C로 중지합니다. 중복 실행은 로컬 잠금으로 차단됩니다.

항상 같은 클라우드 URL에 접속하여 작업하세요. 로컬 전용 화면에서 생성한 작업의 자동 이전은 아직 하지 않습니다. PC가 꺼져 있을 때 Codex 요청은 대기하며, Claude 클라우드 실행은 별도로 사용할 수 있습니다.

## 효율성과 보존
- 실행은 데스크톱 한 개당 하나씩 수행합니다. 대기 조회는 유휴 시 15~60초 간격으로 늦춰집니다.
- 대기열 상태 인덱스로 전체 작업·첨부·결과를 반복 내려받지 않습니다.
- 실행권은 15초마다 확인·갱신합니다. 사용자 중지와 실행권 상실 시 로컬 실행에 중지를 전달합니다.
- 완료 응답 유실 시 `.inno/desktop-pending.json` 한 건을 재전송합니다. 완료 응답을 확인한 대기 기록만 제거합니다.
- 429/서버 오류/일시 연결 오류는 최대 60초 간격으로 재시도합니다. 인증·소유권 등 영구 오류는 중지합니다.
- 생성 파일은 `.inno/desktop-runs`에 보존합니다. 저장량 256 MiB 또는 항목 5,000개를 넘으면 새 작업 수신을 멈춥니다. 사용자 결과를 임의로 지우지 않습니다.
- 원본 입력 내용은 대기열이나 재전송 파일에 보관하지 않습니다.

## 아직 남은 범위
- 클라우드 Codex 작업에 로컬 원본을 다시 연결하는 일시 전달 UI.
- 2분을 넘는 단절 등으로 실행권이 만료된 뒤의 자동 결과 복구. 현재 진행은 일시정지되며 저장된 결과를 검토하여 복구해야 합니다. 무조건 AI를 재실행하지 않습니다.
- 기존 로컬 전용 기록의 선택적 클라우드 이전.
- PC 로그인 시 연결기 자동 시작은 아직 등록하지 않았습니다.

결과 전송이 700,000바이트를 넘으면 로컬 결과를 보존하고 전송을 멈춥니다. 대용량 생성 결과 전달은 후속 단계입니다.
