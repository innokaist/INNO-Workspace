# 실행 토큰 사용량

사용량 화면의 작업별 최근 완료 실행에서 입력·출력 토큰 수를 확인합니다. 데스크톱 Codex 실행기가 보고한 값을 결과와 함께 클라우드 작업 checkpoint에 저장합니다. 실행 ID와 세대에 대한 소유권 검증을 거치며, 미전달 결과 재전송 시 같은 실행을 중복 저장하지 않습니다.

각 작업의 최신 완료 실행 관측값 하나만 유지하며 화면에는 최근 50개를 표시합니다. 새 기록은 기존 실행 기록에 포함되어 별도 로그 테이블을 늘리지 않습니다. 값이 없는 경우 확인 불가로 처리하며 0으로 추정하지 않습니다. 음수·무한대·안전 정수 범위 밖 값과 임의의 실행기 필드는 제외합니다.

실행 중 토큰 스트리밍, 전체 실행 이력 누적 합계, 계정 전체 소비량, 요금, 구독 잔여량을 뜻하지 않습니다. CLI가 마지막으로 보고한 입력·출력 카운터이며 하위 에이전트·캐시·여러 턴의 전체 합산을 독립 검증하지 않습니다. 실패·취소 실행 및 이전 기록에는 값이 없을 수 있고, Claude Routine은 현재 이 경로로 사용량을 제공하지 않습니다. 과거 누락 수치를 소급 생성하지 않습니다. 기록 가져오기 형식에 따라 이 부가 관측값이 유지되지 않을 수 있습니다.

한도와 초기화 시각은 제공자 카드 및 공식 사용량 페이지에서 별도로 확인합니다. 이번 변경은 API 키나 추가 유료 실행을 도입하지 않습니다.
