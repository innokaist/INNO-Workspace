# 이 PC 저장 공간 관리

데스크톱 연결 화면을 새로고침하고 **설정 → 이 PC 저장 공간**을 엽니다. 클라우드 웹 화면만 접속한 휴대폰에서는 PC 파일을 정리할 수 없습니다.

1. 사용량과 시작 전 점검 기준(256 MiB / 5,000 항목)을 확인합니다. 표시는 desktop-runs 내부의 파일 크기 합계이며 디스크 전체 여유 용량은 아닙니다.
2. 완료 실행을 선택하고 폴더와 파일 목록을 확인합니다. 목록은 폴더당 최대 20개 파일명을 보여줍니다. 전체 내용은 E:\Develop\INNO Workspace\.inno\desktop-runs 에서 확인할 수 있습니다.
3. 로컬 파일의 영구 삭제 안내에 직접 체크한 뒤 삭제 버튼을 누릅니다. 중간 파일이 클라우드에 모두 저장되었다는 보장은 없습니다. 필요한 파일을 먼저 보관하세요.

클라우드 완료 작업의 작업 ID·실행 번호·실행 ID가 폴더명과 일치해야 정리할 수 있습니다. 실패·미완료·알 수 없는 폴더는 보호합니다. 실행 중이거나 미전달 결과가 있으면 조회와 정리를 차단하고 새 작업과 동시에 수행하지 않습니다. 조회·정리 전 클라우드 연결도 필요합니다.

연결 경로/심볼릭 링크를 따라가지 않으며 해당 실행은 삭제할 수 없습니다. 조회 후 파일 메타데이터가 변경되면 다시 조회해야 합니다. 실행 폴더 내부 파일만 대상으로 하며 원본 연결 자료, 인증 파일, 작업 DB, 클라우드 기록은 정리 대상이 아닙니다.

정리는 복구 불가능한 로컬 삭제입니다. 외부 프로그램이 파일을 변경하거나 잠그면 일부만 정리될 수 있으며 오류 안내 후 다시 조회해야 합니다. 파일을 편집 중인 외부 프로그램을 닫고 진행하세요. 한 번에 최대 50개 실행을 선택할 수 있습니다. 10,000개 항목을 넘으면 무제한 탐색 대신 중단하고 직접 점검하도록 안내합니다. 용량 조회는 화면을 열거나 새로 조회할 때만 수행합니다.
