# 선택 문헌 비교 작업

1. 연구 자료에서 RefAtlas JSON을 연결합니다.
2. 비교할 문헌 2~8편을 선택합니다. 최소 한 편은 초록이나 제공 본문이 있어야 합니다.
3. **선택 논문으로 비교 작업 준비**를 누릅니다. 연구 목적을 자신의 질문에 맞게 수정합니다.
4. **작업 기록**을 누른 뒤 실행기를 선택하고 **작업 실행**을 누릅니다. 준비 버튼 자체는 AI를 실행하지 않습니다.
5. 결과물에서 comparison.md(근거 비교), ideas.md(최대 3개 아이디어), review.md(한계와 AI 자기검토)를 확인합니다.

## 자료와 재개

문헌 내용은 현재 브라우저 탭의 임시 연결 파일로 구성되어 실행 시 AI 제공자에 전달됩니다. 플랫폼이 원본을 별도 영구 보관하지는 않습니다. 작업 요청에는 서지정보와 읽기 범위만 저장하며, 생성된 요약·결과물은 작업 기록에 남습니다.

탭을 다시 열었다면 같은 RefAtlas JSON에서 같은 문헌을 선택하고 **선택 자료 다시 연결**을 누른 후 기존 작업을 엽니다. 선택 순서는 달라도 됩니다. 내용이나 서지정보가 바뀌면 다른 파일로 식별하므로 기존 자료로 조용히 대체되지 않습니다.

현재 비교용 자료 묶음은 UTF-8 180,000바이트 이내입니다. 초과하면 오류를 표시하며 자동으로 잘라 분석하지 않습니다. 문헌 수나 제공 본문 범위를 줄여 주세요. Codex로 PC 자료를 실행하려면 데스크톱 연결 창과 브리지가 실행 중이어야 합니다. Claude는 구성된 Routine 경로로 임시 자료를 전달합니다.

## 근거와 검증 범위

metadata는 서지정보, abstract는 초록, full-text는 제공된 본문 범위입니다. full-text 표시가 논문 전체를 빠짐없이 읽었다는 뜻은 아닙니다. 추가 요청이 없으면 외부 검색을 하지 않으며, 선택 문헌 밖의 신규성은 검증하지 않습니다.

완료된 문헌 작업의 결과물 위에 형식 점검을 표시합니다. 최신 실행의 세 문서 존재·중복·빈 내용, 문헌 번호 유무·범위·비교표 누락 및 보고된 검토 실패를 점검합니다. review.md는 AI 자기검토입니다. 연구에 활용하기 전 원문과 수치·인용을 확인해야 합니다.

전체 개발 상태: [요구사항 진행표](REQUIREMENTS-STATUS.md).

## 결과 점검과 수정

확인 필요 항목이 있으면 **수정 요청 준비**를 누릅니다. 작성 중인 요청이 있으면 덮어쓰지 않습니다. 같은 자료를 다시 연결하고 요청을 기록한 뒤 실행하세요. 이 버튼은 추가 AI 실행이나 토큰 사용을 자동으로 시작하지 않습니다.

점검은 현재 화면에서 저장된 결과를 읽어 계산하며 새 원문 저장·서버 기록·로그를 누적하지 않습니다. 변경 없는 작업은 계산 결과를 재사용합니다. 실행 완료 상태는 그대로 유지되며 형식 점검 결과는 별도로 표시됩니다. 원래 문헌 목록이 편집되어 해석할 수 없거나 최신 실행 시각이 없으면 확인 필요로 표시합니다.

형식 통과는 주장별 근거의 타당성·수치 정확성·연구 품질의 보증이 아닙니다. 검토 실패 탐지는 한국어/영어의 명시적 실패 표현에 대한 보조 경고이므로 오탐·누락이 가능합니다. 독립 검토 성공을 자동으로 인증하지 않습니다.

## 별도 AI 검토

완료된 비교 작업에서 **별도 검토 작업 준비**를 누르면 원래 문헌 자료와 최신 comparison.md/ideas.md/review.md를 임시 연결한 새 요청을 준비합니다. 원래 작업의 결과는 변경하지 않습니다. 작업 기록 후 실행기를 선택해 실행하세요. 이 실행은 구독 사용량을 소비합니다.

원문 연결이 끊겼다면 연구 자료에서 같은 문헌을 선택하고 **선택 자료 다시 연결**을 누른 후 원래 작업으로 돌아오세요. 자료 내용은 SHA-256으로 원래 첨부와 대조하며, 내용이 다르면 준비를 차단합니다. 비교 결과가 누락·중복·빈 내용이면 먼저 해당 결과를 수정해야 합니다. 검토 대상 결과 묶음도 180 KB 이내이며 자동으로 잘라내지 않습니다.

검토는 하위 에이전트를 호출하지 않고 별도 실행에서 직접 수행하도록 요청합니다. claims.md에는 주장별 출처·읽기 범위·근거 위치·판정·수정안을, review.md에는 오류 우선순위와 미검토 범위를 요청합니다. 별도 AI 실행이며 독립 전문가 검증이나 사실성 보증은 아닙니다. 현재 주장 판정은 AI가 수행하며 프로그램이 의미적 정확성을 확정하지 않습니다.

검토 작업을 나중에 재개하려면 원래 비교 작업에서 같은 자료로 검토 준비를 다시 눌러 임시 자료 두 개를 재구성한 뒤, 새 초안을 기록하지 않고 기존 검토 작업을 여세요. 원래 결과가 바뀌었다면 동일한 검토 대상이 아니므로 기존 검토 입력으로 자동 대체되지 않습니다.
