## 우선순위

1. 선택 논문 비교 흐름의 실제 실행/결과 저장 검증 (이번 단계).
2. 문헌 결과 형식 점검·수정 초안 구현. 별도 AI 검토 작업 및 주장별 근거 판정 요청 구현. 후속: 판정 정확성 평가와 하위 검토 호출 실패의 진단 정보 개선.
3. 연구 데이터의 시료/실험 식별자와 Prism/Ledger/NanoLab 연결.
4. 관측 가능한 토큰/실행 비용을 기반으로 에이전트 구성과 공급자 선택 개선.
5. 문서·Figure·발표자료별 전문 산출 흐름 및 기기별 종합 검증.

## 실험 연결 추가 현황

NanoLab·Ledger·Prism의 식별/계보/주요 분석값 연결 첫 흐름을 구현했다. 전체 합성 조건·원시 측정·보정 검증 및 상시 동기화는 남아 있다. 상세 사용법과 제한은 EXPERIMENT-LINKS.md 참조.

## 방향 변경: Ledger 선택 사항

Ledger 연동은 필수가 아니다. NanoLab·Prism 직접 연결을 기본 연구 데이터 흐름으로 진행한다. 향후 원시 데이터·합성 조건 확장도 Ledger를 전제로 하지 않는다.
